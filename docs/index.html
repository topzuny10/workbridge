파일 이동은 로컬에서 작동합니다. 선택 사항인 WorkBridge Cloud는 업로드 전에 대화를 암호화하지만, 현재 서버는 개인용 self-hosted MVP입니다. 공개 클라우드 서비스가 아닙니다.
